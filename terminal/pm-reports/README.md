# PM Reports (Reserved)

This folder is reserved for **Lead PM authored** tokenized-stock research reports.

## How to use
Create one markdown file per underlying ticker:

- `AAPL.md`
- `MSFT.md`
- `NVDA.md`

The terminal will automatically:
- show report status (found / missing)
- link from Universe → report

## Template

## 1) Executive Summary
## 2) Business Model
## 3) KPIs / What to Track
## 4) Competitive Landscape
## 5) Token Wrapper Details
## 6) Thesis Notes (not long/short)
## 7) Sources
