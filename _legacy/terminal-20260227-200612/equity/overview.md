## How to Use This Terminal

Each company in the universe has a dedicated folder containing:

- **`_Intro.md`** — Start here. Analyst-synthesized brief: business overview, revenue model, competitive moat, bull/bear cases, key metrics to watch, and direct SEC filing links.
- **`_Timeline.md`** — Chronological log of SEC-detected material events (M&A, leadership changes, capital returns, guidance, regulatory filings) from 2020 to present.
- **`Mr_Market.md`** — Daily 9:30am price log, auto-updated from Stooq feed. Use for price context while reviewing research.
- **`_Financial_Model.xlsx`** — Valuation model shell, formatted per archetype. Populate with historical GAAP data and forward assumptions using the build rules in `Universe_Model_Archetypes.md`.
- **`_10-K / _10-Q / _8-K` subfolders** — Full filing indexes with direct SEC EDGAR links organized by form type and date.

**Suggested workflow for due diligence:** Read `_Intro.md` → check `Mr_Market.md` for price context → scan `_Timeline.md` for material events → open relevant filings → build/update `_Financial_Model.xlsx` using the assigned archetype framework.
